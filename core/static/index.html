帮助手册

          PVE WebTools 使用指引
        


        

          快速上手
          
    
            
  • 浏览器访问 https://<PVE_IP>:8899（默认端口 8899）；默认账号 pvewebtools（只输 pvewebtools 等价 pvewebtools@pve）。
    • 
            
  • 顶部五个页签：概览 / 节点管理 / 工具箱 / 传输中心 / 执行日志。
    • 
            
  • 概览每 10 秒自动刷新；右上角「刷新」可手动拉取最新数据。
    • 
            
  • 右上角「设置」里是本帮助手册与当前版本号。
    • 
            
  • 所有写配置的操作执行前都会自动备份，对应工具内提供「从备份恢复」，改坏了可随时还原。
    • 
          

        


        

          各页签能做什么
          
    
            
  • 概览：节点 CPU / 内存 / 硬盘 / 网卡 / 显卡实时概览；虚拟机与容器统一列表，支持搜索筛选、分页、批量启停、开机自启开关、重命名、查看完整配置。
    • 
            
  • 节点管理：集群节点列表；「+ 加入节点」把新 PVE 主机拉入当前集群，并自动完成共享存储挂载与 vBIOS 同步；卡片行尾一个「操作」下拉（重启节点、重启 PVE 服务、一键诊断、关机；后两项结果汇总在列表上方，关机需输入确认词且无远程开机能力），以及工具栏全局的「修复共享存储」按钮——一键修复所有节点：后端先修 NFS 导出端（装/起服务、写 /etc/exports 后重新导出），再逐台重挂客户端 NFS 并铺 vBIOS 软链；离线/占位节点自动跳过，结果在列表上方逐台展示。
    • 
            
  • 节点管理 · 临时取得仲裁：两台集群里一台宕机时，另一台会失去仲裁，PVE 把 /etc/pve 置为只读，于是建机、改配置等写操作全部失败（报 no quorum）。此时可在节点列表页顶部提示条或离线节点行点「临时取得仲裁」（等价的 pvecm expected），把预期票数下调到在线节点数，立刻恢复写操作。它只改运行时票数：不改集群配置、不删节点、不影响任何虚机，corosync 重启后自动失效；失联节点恢复后请点「恢复正常仲裁」还原。出于安全，该按钮仅在在线与不可达节点数相等（偶数集群恰好掉一半）时出现——此时对面票数不足达标门槛、不会双写；奇数集群（3 台及以上）不提供该入口，掉 1 台本来就仍有仲裁。
    • 
            
  • 工具箱：按分类排列的运维工具，可搜索；高危操作需输入工具名确认。
    • 
            
  • 传输中心：向共享存储上传虚机模板 / 云镜像 / 磁盘镜像 / vBIOS ROM；下载官方云镜像与 LXC 容器模板；浏览并批量删除存储内容。
    • 
            
  • 执行日志：工具箱任务历史、步骤时间线与完整日志回看，可按状态筛选、按时间批量清理。
    • 
          

        


        

          工具箱怎么用
          
    
            
  • 进入「工具箱」，左侧按分类列出全部工具，顶部搜索框可按工具名过滤。分类为 日常优化 / 启动与内核 / 硬件直通 / 虚机/容器运维 / 网络工具 / 存储与磁盘 / 诊断与救砖；多数分类顶部有一个「一键」组合工具，可一次完成该分类的常用优化。
    • 
            
  • 使用步骤：点选工具 → 弹窗内填写参数 → 点「执行」。按风险分级确认：只读 直接执行；普通 弹窗内确认一次；高危 须原样输入工具名（服务端校验）。
    • 
            
  • 部分工具会给出前置依赖提示（例如更新软件包前建议先更换软件源），按提示顺序执行可避免失败。
    • 
            
  • 弹窗顶部的「执行节点」决定任务在哪台机器上跑（默认本机＝控制机，也可选其它集群节点）。虚机/容器类操作（快照、克隆、备份、删除、直通、调内核参数等）用的是节点本地的 qm/pct，只能作用于执行节点上的虚机，所以「虚机/容器（VMID）」下拉只列执行节点上的对象：要操作别的节点上的虚机，请先切换执行节点。选错会被服务端直接拦下（给出该虚机属于哪个节点），不会再出现「界面显示成功、其实什么都没做」。
    • 
            
  • 耗时操作在后台执行，弹窗内实时增量显示日志；关闭弹窗任务照常继续，之后到「执行日志」查看结果。
    • 
          

        


        

          建一台虚拟机
          
① 模板快速建机（以 .vma 虚机模板为原料）

          
    
            
  1. 「传输中心 → 上传文件」选「虚机模板」，把 .vma / .vma.zst 上传到共享存储。
    2. 
            
  2. 「工具箱 → 虚机/容器运维 → 模板快速建机」，选中刚上传的模板。
    3. 
            
  3. 填写 CPU / 内存 / 名称，按需调整 BIOS、机型与数据盘后创建。
    4. 
          

          
② 云镜像建机（Cloud-Init 自动初始化）

          
    
            
  1. 「传输中心 → 获取云镜像」选择版本下载，或上传已有云镜像。
    2. 
            
  2. 「工具箱 → 虚机/容器运维 → 云镜像建机」，选中镜像并填写 CPU / 内存 / 名称。
    3. 
            
  3. 勾选 Cloud-Init，填写主机名、登录用户与密码、IP（DHCP 或静态）、DNS。
    4. 
            
  4. 创建后首次启动自动完成初始化，并安装启用 qemu-guest-agent。
    5. 
          

          
③ 创建 LXC 容器（基于已下载模板）

          
    
            
  1. 「传输中心 → 获取 LXC 模板」选版本下载到存储（建议共享存储 pvewebtools）。
    2. 
            
  2. 「工具箱 → 虚机/容器运维 → 创建 LXC 容器」，选中模板并填写 CPU / 内存 / 主机名。
    3. 
            
  3. 按需设置网桥 / 静态 IP（DHCP 或静态）/ root 密码、是否非特权容器，勾选「部署后启动」。
    4. 
          

          
模板与镜像文件存放在共享存储，集群内任一节点建机都能直接取用。

        


        

          硬件直通（显卡 / 网卡 / PCIe / USB / 磁盘）
          
    
            
  1. 执行「直通前置检查」，确认 CPU 虚拟化、IOMMU、分组隔离与驱动占用情况。
    2. 
            
  2. 首次使用先执行「开启硬件直通」（配置 IOMMU + vfio + 驱动屏蔽），完成后重启宿主机。
    3. 
            
  3. 重启后按设备类型选择直通工具：网卡 / 显卡 / PCIe / USB / 磁盘；核显可选「仅计算」纯直通或（Intel）「显示输出 legacy-igd」，独显可选 x-vga 主显卡与 vBIOS ROM。
    4. 
            
  4. 需要 vBIOS 时，先在「传输中心 → 上传文件」选 vBIOS 类型上传，工具会自动同步到各节点。
    5. 
            
  5. 同隔离组内的设备会自动整组直通（组内共享 IOMMU 上下文，无法只挑其中一个）。执行前有一道安全闸门：若整组会连带承载宿主在用盘的存储控制器（AMD APU 平台的核显与 FCH SATA 常同组），或目标存储控制器正被 vfio 占用、无法确认安全，工具会直接拒绝执行并说明原因，不会关机、也不会改配置。
    6. 
          

          
不再需要直通时：先用「移除 VM 全部直通」清掉 VM 上的挂载，再用「回收直通设备」解绑 vfio 并装回原驱动；默认也会移除该驱动的屏蔽配置，重启后能自动加载，无需再单独处理。

        


        

          加入集群 / 扩容
          
    
            
  1. 「节点管理 → + 加入节点」，填写新机器地址与 root 密码。
    2. 
            
  2. 加入成功后自动完成共享存储挂载与 vBIOS 软链同步。
    3. 
          

          
不限制机器数量，也不需要授权码。

        


        

          常见问题（按现象找工具）
          
服务与系统

          
    
            
  • 网页打不开 / 8006 端口不通 → 「诊断与救砖 → PVE 服务诊断」查看核心服务状态，并按依赖顺序一键重启。
    • 
            
  • 系统不对劲但不知道哪里出错 → 「诊断与救砖 → 错误日志速查」聚合 journal + dmesg + 失败单元。
    • 
            
  • WebUI 界面异常 / 虚拟机启动报组件错 → 「诊断与救砖 → 官方组件恢复」重装 WebUI 或 pve-qemu-kvm。
    • 
            
  • 忘记 PVE 登录密码 → 「日常优化 → 重置 PVE 密码」。
    • 
            
  • 系统盘快满、空间告急 → 「日常优化 → 一键释放系统空间」。
    • 
            
  • 根分区不够用（/ 快满） → 「日常优化 → PVE 根分区扩容」（删 swap 扩容根，或删 local-lvm 并入 local）。
    • 
            
  • 更新软件包失败 / 下载太慢 → 「日常优化 → 更换软件源和 LXC 源」换国内源后重试。
    • 
            
  • 不想让系统自动更新 → 「日常优化 → 系统更新与禁止」选「禁止系统更新」。
    • 
            
  • 想立刻打补丁 / 更新软件包 → 同一个工具选「立即更新系统」。
    • 
            
  • 每次登录都弹订阅提示 → 「日常优化 → 删除订阅弹窗」。
    • 
            
  • 风扇吵、功耗高 → 「日常优化 → CPU 调频与节能设置」（性能 / 均衡 / 省电，可持久化，Intel/AMD/ARM 自适应）。
    • 
            
  • SSH 登录慢、输入卡顿 → 「日常优化 → 优化 SSH 连接速度」。
    • 
            
  • 系统时间不准 / 时区不对 → 「日常优化 → 时间同步」（NTP 同步可选国内源 / 主板 RTC 校准 / 时区修改）。
    • 
            
  • 想一次做完常用优化 → 「日常优化 → 一键优化」（组合工具）。
    • 
            
  • 要把 PVE 8 升到 9 → 「日常优化 → PVE 8.x 升级到 9.x」。
    • 
            
  • 想确认当前版本 → 本弹窗标题旁的版本胶囊。
    • 
          

          
启动与引导

          
    
            
  • 开机进不了系统 / 引导项丢失 → 先用「启动与内核 → 启动状态检查」看全局（内核、启动参数、直通状态、EFI 注册、现有备份）。
    • 
            
  • 要加 / 删内核启动参数（iommu、nomodeset 等）→ 「启动与内核 → GRUB 配置」。
    • 
            
  • GRUB 改坏了想还原 → 「启动与内核 → GRUB 配置」里的「从备份恢复」。
    • 
            
  • 装了新内核想设为默认启动 → 「启动与内核 → 内核配置」（安装 / 设默认启动 / 重启应用）。
    • 
            
  • 旧内核太多、占系统盘 → 「启动与内核 → 内核配置」里的「清理旧内核」。
    • 
            
  • EFI 引导项不同步 / ESP 未注册 → 「启动与内核 → EFI 引导维护」（BIOS 引导会自动跳过）。
    • 
          

          
网络

          
    
            
  • 网络不通 / DNS 解析失败 / IPv6 异常 → 「网络工具 → 一键网络诊断」一次看全接口、连通性、DNS、IPv6。
    • 
            
  • 想细查某个地址通不通 → 「网络工具 → 连通性测试」（Ping + DNS 解析 / IPv6 就绪度）。
    • 
            
  • 想先看看当前网络状态 → 「网络工具 → 网络信息」（只读，不改配置）。
    • 
            
  • 改了网卡或网桥配置怕失联 → 「网络工具 → 网络配置管理」：改前自动备份，出问题可从备份恢复。
    • 
            
  • 要新建网桥 / 划 VLAN → 「网络工具 → 网桥与 VLAN」（删除有双重拦截保护）。
    • 
          

          
存储与磁盘

          
    
            
  • 想知道硬盘健康（SMART / 通电时长 / 温度）→ 「存储与磁盘 → 存储状态总览」的深度体检。
    • 
            
  • 只想快速看各存储用量 → 同一个工具的「快速总览」。
    • 
            
  • 旧盘要清空重用 → 「存储与磁盘 → 磁盘分区与格式化」（擦签名 / 全盘覆写 / SSD 安全擦除，自动拦截在用磁盘）。
    • 
            
  • 镜像格式不对（raw / qcow2 / vmdk 互转）→ 「存储与磁盘 → 虚机磁盘格式转换」。
    • 
            
  • 要把虚机迁到 VMware / Hyper-V / 公有云 → 「存储与磁盘 → 虚机磁盘导出」，导出后再传走。
    • 
            
  • 手上已有镜像要变成虚机磁盘 → 「存储与磁盘 → 虚机磁盘导入」。
    • 
            
  • 给虚机加 / 减硬盘 → 「存储与磁盘 → 虚机磁盘新增与移除」（自动填空闲槽位；移除可彻底删除或仅卸载保留文件）。
    • 
          

          
传输中心

          
    
            
  • 要上传虚机模板 / 云镜像 / 磁盘镜像 / vBIOS ROM → 「传输中心 → 上传文件」，按类型选对应目录，上传后集群内各节点都能用。
    • 
            
  • 想下载官方云镜像（Ubuntu / Debian / Alma / Rocky 等）→ 「传输中心 → 获取云镜像」，选版本即带出下载地址。
    • 
            
  • 想下载 LXC 容器模板（Debian / Ubuntu / Alpine 等）→ 「传输中心 → 获取 LXC 模板」，选模板与存储后下载，落盘即可在 PVE 建 CT 时选用；列表来自本机 pveam，点「刷新模板列表」拉取上游最新模板。
    • 
            
  • 共享存储里旧文件太多 → 「传输中心 → 存储内容」浏览并批量勾选删除。
    • 
            
  • 从共享存储建机 / 还原很慢 → 看任务日志开头的「[诊断]」：它会比对链路速率与实测吞吐并直接给出结论（100M 网口≈12MB/s 就是物理极限，也可能是服务端导出盘慢或 NFS 单连接）。工具在新挂载 / 修复共享存储时会自动启用 nconnect=8 多连接（内核或服务端不支持会自动回退，不影响挂载）；已挂载的共享存储要生效，需按诊断给出的方式在维护窗口重挂一次。
    • 
          

          
硬件直通

          
    
            
  • 想确认能不能直通 → 先跑「硬件直通 → 直通前置检查」（CPU 虚拟化 / IOMMU / 分组隔离 / 驱动占用）。
    • 
            
  • 想知道设备被哪个虚机占用 → 「硬件直通 → 直通设备总览」列出所有 VM 的 PCIe / USB / RDM 归属。
    • 
            
  • 首次开启直通 → 「硬件直通 → 开启硬件直通」（IOMMU + vfio + 驱动屏蔽一次配齐，重启后生效）。
    • 
            
  • 直通后 VM 里不认设备 / 显卡报 Code 43 → 「硬件直通 → 显卡直通」，易报 Code 43 的显卡会自动附加推荐参数。
    • 
            
  • 网卡直通怕宿主机失联 → 「硬件直通 → 网卡直通」会自动拦截管理网口，不会让你把管理链路直通出去。
    • 
            
  • USB 设备（键鼠 / U 盘）/ 采集卡 / 声卡要给虚机 → 「硬件直通 → PCIe/USB 直通」（USB 支持热插）。
    • 
            
  • 整块硬盘要给虚机 → 「硬件直通 → 磁盘直通」：块映射 RDM 兼容性最好，PCIe 方式可读原生 SMART。
    • 
            
  • 虚机上的直通设备要全部清掉 → 「硬件直通 → 移除 VM 全部直通」（运行中的虚机会先自动关机，清完自动开回，PCIe 设备自动归还宿主机、无需重启）。
    • 
            
  • 设备没人用、宿主机也用不了（概览显示「未使用（可释放）」）→ 「硬件直通 → 回收直通设备」，立即生效、无需重启。
    • 
            
  • 直通后宿主机装不上驱动（概览显示「无驱动」）→ 「硬件直通 → 回收直通设备」选「仅解除驱动屏蔽」，重启后驱动才会自动加载。
    • 
            
  • 整套直通都不想要了 → 「硬件直通 → 开启硬件直通」选「一键关闭并还原全部直通配置」（含驱动屏蔽，重启生效）。
    • 
            
  • 直通后宿主机起不来 / 管理口失联 → 检查「直通设备总览」确认设备归属；管理网口直通会被工具自动拦截，不要改配置绕过。
    • 
            
  • 提示「会涉及存储控制器 …已拒绝执行」（显卡 / 网卡整组直通被拦下）→ 该隔离组里混着承载宿主在用盘的存储控制器（AMD APU 核显常与 FCH SATA 同组），整组直通会把宿主盘交给虚机、宿主机随即掉盘。先把 /var/lib/vz 等宿主在用盘迁到别的控制器（如 NVMe 上的存储）再试；设备若还在 vfio 里，先「回收直通设备」还给宿主驱动。
    • 
            
  • 直通后宿主机磁盘消失 / 虚机开机报 qcow2 Input/output error → 同一成因：整组直通连带走了宿主盘所在的存储控制器。先把直通删掉再排查：qm set <VMID> -delete hostpci0，确认 lspci -k 里该控制器已回到 ahci、磁盘重新出现后再开机（每次开机都会重复掉盘，别反复尝试）。
    • 
            
  • 「回收直通设备」停在「已从 vfio-pci 解绑」不动 → 多数是正常等待：装回 ahci / nvme 时内核要逐端口复位并重新识别磁盘，慢时 1~2 分钟。工具已加 180 秒超时与进度提示；真超时多为盘/链路异常，可看 dmesg 里的 ata 日志，必要时重启宿主机。
    • 
          

          
虚机与容器

          
    
            
  • 建机慢、要重复建多台 → 「虚机/容器运维 → 模板快速建机」（以 .vma 虚机模板建机，自动识别系统）；批量模式会先把模板/镜像预拉取到本机再逐台建机，后续几台直接读本地盘，不受网络存储拖累。
    • 
            
  • 想让它开机自动初始化（主机名 / 用户密码 / IP / DNS）→ 「虚机/容器运维 → 云镜像建机」勾选 Cloud-Init。
    • 
            
  • 建 LXC 容器（轻量、共享内核） → 「虚机/容器运维 → 创建 LXC 容器」（基于「获取 LXC 模板」下载的模板，可选非特权容器、设 root 密码与网络）。
    • 
            
  • 改配置前想留退路 / 改坏了要回滚 → 「虚机/容器运维 → 快照」（创建 / 回滚 / 删除）。
    • 
            
  • 虚机/容器要定时开关机 → 「虚机/容器运维 → 定时开关机」。
    • 
            
  • 要整机备份 / 还原 → 「虚机/容器运维 → 备份与还原」（在线备份、可压缩、可指定存储）。
    • 
            
  • 想复制一台虚机/容器 → 「虚机/容器运维 → 克隆虚机/容器/模板」（完整克隆 / 链接克隆）。
    • 
            
  • 要删虚机/容器（连带磁盘 / 备份） → 「虚机/容器运维 → 删除虚机/容器/模板」。
    • 
            
  • 虚机起不来、要临时加内核参数（如显卡直通用的 nomodeset）→ 「虚机/容器运维 → 调整虚机内核参数」。
    • 
            
  • 看不清虚机/容器的完整配置（核数 / 磁盘 / 网卡）→ 概览页点名称查看配置详情。
    • 
            
  • 要给虚机写备注 → 概览列表最右侧「备注」列直接编辑。
    • 
          

          
概览与虚机/容器操作

          
    
            
  • 虚机/容器很多、要批量启停 → 概览页勾选多个虚机/容器后批量启动 / 关机 / 强制停止 / 重启。
    • 
            
  • 想让某台虚机/容器开机自启 → 概览列表「开机自启」列点击切换。
    • 
            
  • 虚机/容器名字要改 → 名称旁的铅笔图标。
    • 
            
  • 只想看某个节点的虚机/容器 → 点节点卡片筛选（或顶部节点标签），再点标签上的 ✕ 清除。
    • 
            
  • 数据看着不新 → 右上角「刷新」手动拉最新（概览本身每 10 秒自动刷新，慢采集项走后台缓存）。
    • 
          

          
授权

          
    
            
  • 需要授权码 / 机器数量限制吗 → 不需要：不限机器数量、没有授权码。
    • 
            
  • 加节点失败怎么排查 → 确认新节点 root 密码正确、22 端口可达，且本机已装 ssh 与 setsid。
    • 
          

          
通用

          
    
            
  • 页面提示 Failed to fetch → 多为瞬时并发请求过多或服务未运行，稍后重试即可；
              重启服务后刷新页面也能恢复。
    • 
            
  • 改完配置没生效 → 内核启动参数、硬件直通、网络配置等改动需要重启节点才生效；到「节点管理」对应节点行尾点「重启节点」（需输入确认词「重启节点」）。
    • 
            
  • 想找回改坏前的配置 → 写配置前均有自动备份，对应工具内提供「从备份恢复」。
    • 
            
  • 任务跑太久想中止 → 执行弹窗里的「强制结束」，之后可在「执行日志」查看轨迹。
    • 
            
  • 执行记录会丢吗 → 重启后仍可查，默认保留最近 200 条，可在「执行日志」页按时间批量清理。
    •
